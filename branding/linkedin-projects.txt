1. REAL-TIME CHAT
============================================================

PROJECT NAME
Real-time Chat

DESCRIPTION
A WhatsApp-style messaging app, built end to end with a React front end and a Node.js API.

• Passwordless sign-in: you enter your email, get a 6-digit code and you're in. An account is created on your first login.
• Find people by email and chat one-to-one in real time over Socket.IO. Every message is saved in MongoDB, so the full history loads when you open a chat.
• Messages sync across all your open tabs and devices. If someone new messages you, they show up in your chat list even if you were offline when they sent it.
• Familiar chat interface with message bubbles, timestamps, and day labels (Today, Yesterday, then the date). On phones it switches to a single-panel layout.
• Secure sessions in httpOnly cookies, so page scripts can't read them. The same login protects both the API and the live chat connection.
• Front end hosted on Cloudflare, API on Render.

SHORT DESCRIPTION
WhatsApp-style real-time chat with email OTP login, built with React, Socket.IO, Express and MongoDB.

SKILLS
React.js · Socket.IO · Node.js · Express.js · MongoDB

2. URLSHORTY: URL SHORTENER
============================================================

PROJECT NAME
URLShorty: URL Shortener

DESCRIPTION
A link shortener with user accounts, built with Node.js, Express 5 and MongoDB.

• Sign up in three steps: enter your name and email, confirm it with a 6-digit code, then choose a password. Only verified accounts can sign in.
• Paste a long link to get a short one, then copy it or download it as a QR code (PNG or SVG).
• Every link counts its clicks. Your private dashboard lists all your links with their click totals, and you can delete any of them.
• Sign-in codes are stored hashed, expire after 10 minutes and lock after five wrong tries. Sessions use httpOnly cookies.
• Server-rendered pages with light and dark themes, set up for search engines with page titles, descriptions and a sitemap.
• Runs as serverless functions on Vercel.

SHORT DESCRIPTION
A URL shortener with user accounts: sign up with an email code, shorten links, track clicks and download QR codes. Built with Node.js, Express 5 and MongoDB.

SKILLS
Node.js · Express.js · MongoDB · JSON Web Token (JWT) · Vercel

3. YOURLABTEST
============================================================

PROJECT NAME
YourLabTest

DESCRIPTION
A community-funded supplement testing platform, built as a React and Express monorepo. Lab-testing a single supplement costs too much for one person, so the idea is for people to vote on the products they want tested and share the cost.

This beta covers the voting side:
• Browse supplement categories such as whey protein and creatine, with live product and category counts.
• Each category page groups products by brand and sorts them by votes, with brand filters and search.
• Tap "I'm Interested" to vote for a product. Votes are saved in MongoDB.
• An admin panel to add, edit and bulk-delete products, and to create new brands as you go.
• React 19 and Material UI on the front end, with an Express 5 API on MongoDB.

SHORT DESCRIPTION
A community-funded supplement testing platform (beta). People browse supplements by category and brand and vote for the ones they want lab-tested, with an admin panel to manage products. Built with React, Material UI, Express 5 and MongoDB.
